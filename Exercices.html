Entraînez-vous sur Python

Choisissez votre niveau et forgez vos compétences du code à travers des défis concrets.

Exo 1 • Variables

Le Calculateur d'Âge

Écrivez un script qui demande l'année de naissance de l'utilisateur, calcule son âge actuel et l'affiche dans une phrase complète.

Exo 2 • Conditions

Le Juste Prix des Places

Demandez l'âge d'un visiteur : s'il a moins de 18 ans, affichez "Tarif réduit : 5€". Sinon, affichez "Tarif plein : 10€".

Exo 3 • Boucles

La Table de Multiplication

Générez et affichez proprement la table de multiplication du nombre 7 (de 1 à 10) en utilisant une boucle for.

Exo 1 • Listes & Logique

Le Tri sélectif

Soit une liste de nombres de 1 à 20. Créez un script qui sépare cette liste en deux nouvelles listes : une contenant uniquement les nombres pairs, l'autre les impairs.

Exo 2 • Fonctions

Le Générateur de Mots de Passe

Créez une fonction qui prend en paramètre une longueur de caractères et renvoie un mot de passe aléatoire contenant des lettres miniatures, majuscules et des chiffres.

Exo 3 • Dictionnaires

Gestionnaire de Contacts

Créez un mini-répertoire téléphonique en utilisant un dictionnaire. L'utilisateur doit pouvoir chercher un nom et obtenir le numéro associé.

Exo 1 • POO

Le Simulateur de RPG

Créez une classe Personnage avec des attributs (nom, vie, attaque) et une méthode attaquer(cible). Faites s'affronter deux instances jusqu'à la défaite de l'une d'elles.

Exo 2 • Fichiers & Regex

Analyseur de Log Web

Ouvrez un fichier texte brut simulant des logs serveur. Utilisez les expressions régulières (Regex) pour extraire toutes les adresses IP uniques présentes dans le texte.

Exo 3 • Algorithmie

Le Tri à Bulles

Implémentez manuellement l'algorithme du tri à bulles pour trier une liste de nombres désordonnés sans utiliser la fonction native .sort() de Python.

Projet 1 • Automatisation

Le Web Scraper de Prix

Développez un script avec BeautifulSoup ou Selenium capable d'extraire le prix d'un produit spécifique sur un site e-commerce et de vous l'envoyer par email.

Projet 2 • Application Web

To-Do List API avec Flask

Concevez une application web de gestion de tâches complète en utilisant Flask et une base de données SQLite (Opérations CRUD complètes).

Projet 3 • Data Science / IA

Prédicteur de Prix Immobilier

Utilisez la bibliothèque Scikit-Learn pour entraîner un modèle de régression linéaire simple capable de prédire le prix d'une maison selon sa surface.
